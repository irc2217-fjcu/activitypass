# 區資護照 (activitypass)
### 北區區域原住民族學生資源中心 · 研習時數查詢系統

本系統為北區區域原住民族學生資源中心（輔仁大學）之學員研習時數專用查詢與證明匯出系統。
前端採用純靜態 Single Page Web App，可直接透過 **GitHub Pages** 免費且穩定託管；後端串接 Google Apps Script (GAS) 與 Google 試算表作為雲端資料庫。

---

## 🌟 系統特色

1. **純查詢與證明列印**：免繁雜填報與佐證上傳，提供極簡、安全、直覺的時數查詢體驗。
2. **雙重身分核對驗證**：學員輸入「身分證字號」與「出生年月日 (西元)」比對試算表之學員名冊，保障個人隱私。
3. **開課單位整合統計**：依據不同「開課單位」彙整通過時數，並提供小計卡片與清單明細。
4. **年份篩選與即時重算**：支援下拉選單切換研習年份（全部年份 / 2024 / 2025 / 2026...），動態重新計算該年度總時數與單位分布。
5. **標準 A4 研習證明書列印 / 匯出 PDF**：內建 A4 列印排版與色彩鎖定樣式，支援末五碼證號隱碼遮罩，點擊按鈕即可一鍵列印或另存為 PDF。

---

## 📂 專案檔案結構

- **`index.html`**：前端 SPA 主程式，包含身分驗證、時數看板、開課單位統計、明細列表與 A4 證明書列印功能。
- **`Code.gs`**：Google Apps Script (GAS) 後端核心代碼，處理試算表比對、時數匯總與 API 回應。
- **`README.md`**：專案設定與使用說明文件。

## 🚀 部署與使用說明

### 一、啟用 GitHub Pages（前台網址發布）

1. 進入此 GitHub 倉庫：`https://github.com/irc2217-fjcu/activitypass`
2. 點擊上方 **Settings** 標籤頁。
3. 在左側選單點擊 **Pages**。
4. 在 **Build and deployment** 下的 **Branch** 選擇：
   - 分支：`main`
   - 資料夾：`/ (root)`
5. 點擊 **Save** 儲存。
6. 等候約 1~2 分鐘，即可透過專屬網址開啟系統：
   👉 **`https://irc2217-fjcu.github.io/activitypass/`**

---

### 二、後端 Google Apps Script (GAS) 設定

若需重新部署或更新 GAS 服務：

1. 開啟共用的 Google 試算表（ID: `12lHpaiWIYeuBzTum8KNEfUPKvTm0PDpMrXODrf2sHa8`）。
2. 點擊上方選單 **擴充功能** -> **Apps Script**。
3. 將本專案中的 `Code.gs` 複製並貼上到 Apps Script 編輯器中。
4. 點擊右上角 **部署** -> **管理部署作業** 或 **新增部署作業**：
   - 種類：**網頁應用程式 (Web App)**
   - 執行身分：**我 (您的 Google 帳號)**
   - 誰可以存取：**所有人 (Anyone)**
5. 部署完成後複製「網頁應用程式網址」，並確認 `index.html` 中的 `API_URL` 常數設定一致。

## 📊 資料庫欄位結構參考

- **工作表1 (時數總表)**：
  - `Col A (0)`：姓名
  - `Col B (1)`：身分證字號
  - `Col C (2)`：開課單位 / 服務單位
  - `Col D (3)`：課程編號 / 課程分類
  - `Col E (4)`：課程名稱
  - `Col F (5)`：活動開始時間
  - `Col G (6)`：活動結束時間
  - `Col H (7)`：時數
  - `Col I (8)`：審核欄位 (通過 / 待審核 / 不通過)
  - `Col J (9)`：佐證圖片連結
  - `Col K (10)`：紀錄ID
- **學員名冊 (會員驗證)**：
  - `Col A (0)`：姓名
  - `Col B (1)`：身分證字號
  - `Col C (2)`：出生年月日
  - `Col D (3)`：服務單位
  - `Col E (4)`：管理員標記 (V)
